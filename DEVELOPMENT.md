# Villages development workspace

This folder contains Villages and the focused source, build, and regression files needed to work on it. It is a Villages-only development copy, not a complete checkout of the official Marinara-Agents monorepo. The original source workspace is preserved under `marinara-villages/` inside this folder and ignored by Git. Work from the Villages files at the repository root; do not modify or track that preserved source copy.

## Build

Requires Node.js 24 or newer and an installed Marinara Engine checkout with its dependencies. In PowerShell:

```powershell
npm ci
$env:MARINARA_ENGINE_ROOT = 'C:\Users\dsbwi\Desktop\Marinara-ENgine-LatestStaging'
node scripts/build-feature-packages.mjs villages
```

Change `MARINARA_ENGINE_ROOT` if your Engine checkout is elsewhere. Before packaging a code change, increment Villages `version` in the `villages` entry of `scripts/build-feature-packages.mjs`. The build uses the Engine source snapshot under `sources/engine`, overlays Villages source, and writes generated files under `packages/villages/`, a zip under `artifacts/`, and a Villages-only local catalog under `catalog/`. The local catalog is ignored by Git because its URLs target the official multi-agent repository.

## Install into the existing Engine

The Engine's installed package registry must already contain a Villages entry. It currently does on this machine. After building, run:

```powershell
$version = (Get-Content packages/villages/manifest.json -Raw | ConvertFrom-Json).version
$archive = ".\artifacts\villages-$version.zip"
node scripts/sideload-villages.mjs $env:MARINARA_ENGINE_ROOT $archive villages
```

The helper copies the generated `packages/villages/` output into the Engine's versioned capability-package directory, updates its installed-package registry, and saves a registry backup. Restart Marinara Engine afterward so it loads the updated server package.

The local catalog generated by this Villages-only copy uses artifact and documentation URLs under `Pasta-Devs/Marinara-Agents`. Use the sideload command above for this local workspace; do not publish its single-package catalog as a replacement for the official multi-agent catalog.

## Checks

```powershell
npm run check
```

Focused Villages tests are under `tests/`. Package source and generated outputs are under `packages/villages/`.

## Git scope

This is a selected subset for a Villages-only working repository. It is not suitable for replacing the official Marinara-Agents repository, which tracks all agent packages and their shared catalogs. If you later want to contribute Villages into that official monorepo, use a full checkout and transfer only the Villages changes into it. You handle all Git operations for this folder.
