# Building Villages

This repository contains the Villages package source, build tooling, and tests. It is a selected subset of the Marinara-Agents source tree.

## Build

Requires Node.js 24 or newer and an installed Marinara Engine checkout with its dependencies. In PowerShell:

```powershell
npm ci
$env:MARINARA_ENGINE_ROOT = Read-Host 'Path to the installed Marinara Engine checkout'
node scripts/build-feature-packages.mjs villages
```

Change `MARINARA_ENGINE_ROOT` if your Engine checkout is elsewhere. The Villages package version is defined by the `villages` entry in `scripts/build-feature-packages.mjs`. The build uses the Engine source snapshot under `sources/engine`, overlays Villages source, and writes generated files under `packages/villages/`, a zip under `artifacts/`, and a Villages-only local catalog under `catalog/`. The local catalog is ignored by Git because its URLs target the official multi-agent repository.

## Install a built package

The sideload helper installs Villages into either an existing package registry or a fresh data directory. It preserves other installed package records and saves a registry backup when one already exists. To install the generated package into a compatible Engine, run:

```powershell
$version = (Get-Content packages/villages/manifest.json -Raw | ConvertFrom-Json).version
$archive = ".\artifacts\villages-$version.zip"
node scripts/sideload-villages.mjs $env:MARINARA_ENGINE_ROOT $archive villages
```

The helper copies the generated `packages/villages/` output into the Engine's versioned capability-package directory and updates its installed-package registry. Restart Marinara Engine afterward so it loads the updated server package.

The local catalog generated by this Villages-only copy uses artifact and documentation URLs under `Pasta-Devs/Marinara-Agents`. This single-package catalog is not a replacement for the official multi-agent catalog.

## Checks

```powershell
npm run check
```

Focused Villages tests are under `tests/`. Package source and generated outputs are under `packages/villages/`.
