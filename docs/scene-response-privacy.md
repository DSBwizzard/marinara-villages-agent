# Scene response privacy

The registered active, command and archive handlers project `session` and `visit` through one explicit public authority contract. Current access, visible participants, progress counts, a compact latest-turn publication proof and safe operation summaries are separate from a bounded playback window. Responses omit submissions, frozen facts, whole-Venue attendance, private contact lines, raw checkpoints and provider evidence. Playback metadata never duplicates its prose. Other payloads and explicit owner diagnostics retain their own contracts.

Historical playback contains complete main/aside moments with the exact saved public staging at their first and last paragraphs. Its cursors expose public moment identities and digests, never private offsets or source heads. Hidden-only updates do not change public anchors or versions. History reads hold existing work admission until all referenced pages are loaded; cleanup validates their current, frozen, checkpoint and Undo owners before deletion.

Projection performs no model request and changes no saved authority. Provider-free tests exercise the actual route boundary and native page/query services, including hidden contents, arbitrary private fields, complete moments, interrupted publication and cleanup races. Packaged Engine verification remains separate from these tests.

## Narrated sounds

New Zone responses weave nonverbal sounds into ordinary narration. An optional `sound: { sourceId, text, loud? }` on a narration segment routes its audible component using captured positions and the existing ordinary/very-loud reach rules. The paragraph remains player-observable prose; `sound.text` is an audible-only description of at most 300 characters. Source IDs are private routing data, not permission to name unseen sources in prose. One source is supported per annotated segment, evaluated after any validated movement at that segment. The player must be within sound reach.

The full narration keeps only local visual witnesses. Remote listeners receive the existing private `soundOnly` view under the same line ID, without the surrounding actions; the narration index does not give them evidence of those actions. Public responses omit routing metadata and never add a second sound paragraph. The saved representation reuses `soundOnly`, so existing scenes need no migration. Legacy standalone sound segments remain readable for recovery compatibility. No extra model call or automatic prose rewrite is introduced.
